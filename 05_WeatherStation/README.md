# Weather Station

A mini weather station that shows temperature and a weather message on a 16×2 LCD.
Custom icons (sun, cloud, rain, snow, heart) change based on temperature and light level.

**Components:** Arduino Uno, LCD 16×2, TMP36, photoresistor, 10 kΩ potentiometer (contrast), resistors.
**Concepts:** `LiquidCrystal.h`, `lcd.createChar` (custom icons), `millis()` timing without `delay`.
