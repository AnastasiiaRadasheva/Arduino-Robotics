# Night Lamp

A multi-mode night lamp with an RGB LED. A potentiometer selects the colour (red / green / blue),
and a photoresistor (LDR) measures room light to control the LED.

**Components:** Arduino Uno, RGB LED, photoresistor, potentiometer, 220 Ω resistors.
**Concepts:** `analogRead`, `analogWrite` (PWM), `map`, `constrain`.
