# Smart Trash Bin

A touchless trash bin. An ultrasonic sensor detects a hand closer than 50 cm and a servo opens the lid.
The LCD shows whether the bin is open or closed, and an RGB LED turns green or red.

*Pair project.*

**Components:** Arduino Uno, ultrasonic sensor (3-pin HC-SR04), SG90 servo, LCD 16×2, RGB LED, potentiometer.
**Concepts:** `pulseIn` distance measurement, `Servo.h`, `LiquidCrystal.h`.
