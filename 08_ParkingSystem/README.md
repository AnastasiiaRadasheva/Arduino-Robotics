# Parking System

A parking lot with a barrier. Two ultrasonic sensors detect cars entering and leaving and count free spots (max 5).
A servo lifts the barrier, the LCD shows free spots, and an RGB LED shows the status (green = open, blue = closed, red = full).

*Pair project, built with a cardboard model.*

**Components:** Arduino Uno, 2 × HC-SR04, servo, RGB LED, LCD 16×2, resistors.
**Concepts:** functions, counters, `pulseIn`, `Servo.h`, `LiquidCrystal.h`.
