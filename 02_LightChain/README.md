# LED Light Chain

A row of 10 LEDs with 5 blinking modes. A potentiometer selects the mode:
all blink, one by one, reverse, random "candle" effect and wave.

**Components:** Arduino Uno, 10 LEDs, resistors, potentiometer (A0).
**Concepts:** `analogRead`, `map`, `constrain`, `switch`, arrays, `random`, Serial Monitor.
