# Alarm System

A small alarm system that monitors temperature and light and shows them on an LCD.
It works only in the dark. If the temperature leaves the safe range, a buzzer plays an alarm signal.

**Components:** Arduino Uno, LCD 16×2, TMP36, photoresistor, piezo buzzer, resistors.
**Concepts:** `tone` / `noTone`, `millis()`, state flags, `LiquidCrystal.h`.
